# Test 05 — Landing page de producto

**Carpeta destino:** `src/tests/05-landing/<TU-MODELO>/View.tsx`

**Que mide:** diseno de marketing, jerarquia visual, animaciones sutiles y responsive
en una pagina orientada a conversion.

Lee primero `prompts/00-reglas-base.md`.

## Prompt

Crea una landing page para un producto SaaS ficticio dentro de `View.tsx`:

- Navbar sticky con logo, links y boton CTA.
- Hero con titulo grande, subtitulo, dos botones (CTA principal y secundario) y una
  imagen/ilustracion de producto (puede ser CSS/SVG).
- Seccion de features (al menos 3) con iconos.
- Seccion de precios con 3 planes y uno destacado.
- Seccion de FAQ tipo acordeon funcional.
- Footer completo.
- Animaciones sutiles de entrada/scroll (framer-motion o CSS) sin que mareen.
- 100% responsive.

Podes separar en subcomponentes dentro de tu carpeta. Exporta el componente principal
por defecto.
