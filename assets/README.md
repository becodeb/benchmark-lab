# assets/

Imagenes de referencia para los tests que usan vision.

## Test 04 — Copiar una UI

1. Guardá una captura de pantalla (PNG) del componente o landing que quieras replicar.
2. Nombrala exactamente `04-target-ui.png`.
3. Dejala en esta carpeta.
4. Decile al agente: `hace el 4`.

Recomendaciones para una buena prueba:
- Que tenga jerarquia clara: titulos, texto, botones, iconos, tarjetas.
- Resolucion razonable (no un thumbnail de 100px).
- Un solo componente o seccion, no una pagina entera gigante.
